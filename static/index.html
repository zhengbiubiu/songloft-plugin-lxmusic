🎵 LX Music Plugin

连接 LX Music Sync Server，为 Songloft 提供多平台免费音乐搜索与播放

服务连接
LX Music Sync Server 的 HTTP 地址（默认端口 9527）。例如部署在 NAS 上：http://192.168.1.100:9527
高级（可选）
音箱直连播放 /stream 路由时使用。留空自动推导（从 baseUrl host / getHostUrl / 网卡 LAN 地址依次尝试）。如反代或多网卡环境推导失败时手动填写。
搜索平台
topone 端点（小爱语音点歌 / 外部搜索）会按从上到下顺序依次搜索，酷我 kw 免费资源多建议优先。
